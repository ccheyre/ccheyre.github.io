Beyond Search: LLM Adoption and Web Traffic Concentration

Do large language models replace web search and pull traffic away from websites? Using comScore browsing data from 2022 to 2024 and the staggered timing of users' LLM adoption, we find that adoption is followed by a sustained increase in the number of unique websites users visit. Whereas search engines funnel traffic toward a narrow set of destinations, LLMs spread users across a wider range of websites.

Samira Gholami*, Cristiana Firullo*, Cristobal Cheyre, Alessandro Acquisti
